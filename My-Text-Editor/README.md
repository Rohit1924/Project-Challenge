# 📝 My Text Editor

A simple **Text Editor** built with **Python and Tkinter**.

This project is part of my **30 Days Project Challenge**.

## 🚀 Features

### 📁 File
- New
- Open
- Save
- Exit

### ✏️ Edit
- Undo
- Redo
- Cut
- Copy
- Paste
- Select All
- Delete

### 👁️ View
- Zoom In
- Zoom Out
- Reset Zoom

## 🛠️ Technologies

- Python
- Tkinter
- File Handling

## ▶️ Run

```bash
python text_editor.py
```
